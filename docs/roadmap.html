Reading your disc

Complete

Pure-Rust disc stack, testable without a disc. No game data ever lives in the repo — tests use made-up data, and the game still starts without a disc on placeholder art.

  • Open ISO/GCM/CISO, check the GameCube magic number and game ID, parse the FST, read files by pathPasses on Philip's disc. disc_path via --disc, settings.json, or a rom/ folder.
  • Yaz0 (.szs) decoder
  • main.dol extraction, foresta.rel.szs decompression — 72,924 REL pointers resolve
  • Asset table: 39,861 assets (name → ROM offset, size, source), offsets match rustimal-crossing
