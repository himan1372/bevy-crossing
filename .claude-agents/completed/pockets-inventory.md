# pockets-inventory — 15-slot pockets on logic::inventory
- [x] Pockets backed by logic::inventory::Inventory (15 slots, item IDs + 2-bit conditions); replaces the fruit/fish/bug/furniture counters.
- [x] Item kinds the slice needs (fruit, fish, bug, furniture, quest items) with display names; full-pockets handling.
- [x] Pockets UI (open/close with a key; uses InputFocus).
- [x] Catches, fruit pickup, shop buy/sell and quests read/write pockets; save/load pockets.
- [x] Gate passes; live BRP check; Philip playtest.
