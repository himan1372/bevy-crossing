The “models” are code-linked display lists.

Animal Crossing on GameCube carries its Nintendo 64 rendering architecture forward. Geometry is stored as Vtx arrays and Gfx command lists, then translated to GameCube GX at runtime—not loaded as BMD files.

01

What format is a model?

A model is not a standalone file with a header or revision field. It is a collection of compiled arrays linked into the executable or REL.

ASSET DATAVtx + Gfx

Mixed-width vertices, CI textures, palettes, display-list commands.

INTERPRETERemu64

Reads Fast3D-derived commands and custom Dolphin extensions.

GAMECUBE APIGX

Receives translated geometry, texture, combiner, and matrix state.

OUTPUTRendered scene

The selected actor or object model appears in-game.

Furniture & props

Usually a single static display list, with no skeleton.

  • *_v vertex arrays
  • *_model / *_gfx commands
  • *_pal and *_tex image data

Fish & insects

Multiple body-part display lists; numbered insect suffixes are wing-animation frames.

  • Shared vertex pools
  • Opaque or translucent lists
  • No distance-based LOD found

Villagers

Per-species cKF skeletons assemble roughly ten body-part display lists with per-bone matrices.

  • 72 species model files in the decomp
  • 8 eye and 6 mouth variants
  • Clothing/face textures supplied per instance

02

Which version reaches the screen?

Runtime selection is identity-driven, not distance-driven. The engine resolves an actor profile and object bank, then binds skeleton, part lists, and instance textures where needed.

No LOD system found

Searches of actor and draw code found frustum culling—ACTOR_STATE_NO_DRAW_WHILE_CULLED—but no distance-based model swap. “1” and “2” on insect parts denote wing-flap frames.

Selection tables do the work

actor_dlftbls has 246 profile entries. m_actor.h defines 700+ object banks. Villagers additionally resolve species, cKF skeleton, body-part lists, and eye/mouth/clothing texture indices.

Actors are not streamed from disc

The actor table’s rom_start and rom_end fields are marked unused in Animal Crossing. The game’s working content is RAM-resident after boot.

“Duplicate” needs care

No confirmed second copy of the same model was found. A shared DUMMY model serves many item IDs. Much of the decompressed REL is unreachable through known asset tables, but that span includes code and other data—not proven duplicate models.

Extraction implication

Start from DOL/REL offsets, not filenames. The PC ports generate per-asset tables of absolute offsets plus swap classes: NONE, U16, U32, and VTX.

Endianness implication

Vtx records mix 16-bit positions with 8-bit colors and need a dedicated swap routine. CI palettes are N64-endian and converted when loaded.

04

Models that ship but stay hidden

These are unused or normally unreachable cases identified by community documentation and cross-checked against decomp filenames where possible.

  • xsq — unused squirrel; present as xsq_1.c, spawnable only through memory editing.
  • Debug Gyroid — test-map assistant with corrupted textures and no animations.
  • ac_mbg, ac_airplane, ac_mural — test actors, debug-map or unnamed-item only.
  • Eight fossil bases — ac_din_*_dummy.c unobtainable furniture.
  • DUMMY-shared items — multiple item IDs resolve to one shared placeholder model.
  • ac_hayakawa_famicom — duplicate “Legend of Zelda” item; crashes on interaction.
  • SMB / Zelda NES items — functional but unobtainable; ROMs are inside famicom.arc.
  • Eight clothing items — unobtainable by the player, but villagers wear them at events.
05

What remains unverified

The evidence is strong on the rendering pipeline and USA Rev 0 layout. These edges should stay marked as open rather than filled with guesses.

Could “cMP” come from a specific tool or post?

No examined source uses that name for GameCube model data. A concrete origin is needed to trace the terminology.

What is inside the two forest ARCs?

The files are confirmed RARC graphics archives DMA’d into ARAM, but this research did not enumerate their internal filenames.

Is there absolutely no LOD anywhere?

No LOD system was found in the decomp code examined; the evidence shows culling instead. This remains an absence-of-evidence claim, not a mathematical proof.

Where is the reported whale model?

A community video references it, but its binary or decomp location was not verified.

Do other regions match exactly?

No. These disc-layout findings are for USA Rev 0 (GAFE01). Known content changes exist across Doubutsu no Mori, DnM+, Animal Crossing, and DnM e+.
